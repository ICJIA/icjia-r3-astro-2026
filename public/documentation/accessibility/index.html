ℹ️ What are "Incomplete Checks"?

Incomplete checks are accessibility rules that axe-core could not definitively pass or fail. These typically require manual review because:

  • Color Contrast: Some color combinations need human judgment (e.g., text over images, gradients)
  • Dynamic Content: Elements that change state or visibility may need testing in different contexts
  • Semantic Meaning: Automated tools cannot always determine if content is semantically appropriate
  • Context-Dependent: Some accessibility requirements depend on the surrounding context or user intent

Incomplete checks are not failures—they are opportunities for manual verification to ensure the best possible accessibility.
